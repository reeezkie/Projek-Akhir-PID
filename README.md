Repositori ini berisi dokumentasi lengkap dan kode sumber untuk **Projek Akhir Pemrosesan Infrastruktur Data**. Sistem ini dirancang untuk membangun alur kerja (*pipeline*) data pertanian dari hulu ke hilir guna memprediksi produktivitas hasil panen secara akurat demi mendukung pengambilan keputusan berbasis data (*data-driven decision making*).

## 💡 Latar Belakang
Sektor pertanian memegang peranan krusial dalam rantai pasok pangan global. Tantangan utama seperti fluktuasi iklim dan ketidakpastian hasil panen seringkali memicu krisis pangan. Melalui proyek ini, dibangun sebuah infrastruktur data yang andal untuk mengolah berbagai parameter pertanian, menyaring anomali data, hingga menghasilkan model prediksi produktivitas panen yang membantu mengoptimalkan hasil pertanian sejalan dengan target *Sustainable Development Goals (SDGs): Zero Hunger*.
